# Shark Game

Shark Game is a browser mini-game developed as a final project for the academic lecture "3D Graphics in OpenGL". The project is implemented using WebGL, creating an immersive 3D underwater world. 🌊

In this game, you control a shark using the W, A, S, D keys. Your goal is to catch as many fish as possible within 60 seconds! 🐟

**Play the game here:** [Shark Game](https://shark-game-webgl.netlify.app/)  
⚠ Please note that rendering all objects and loading the page may take a few seconds.
